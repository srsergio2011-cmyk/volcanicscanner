# VolcanicScanner

Generador de códigos QR con estilo volcánico y una interfaz moderna para crear, personalizar y descargar QR en PNG.

## Funcionalidades

- Crea QR para texto, enlaces, WhatsApp y tarjetas de contacto.
- Personaliza tamaño, margen, color principal y fondo.
- Vista previa en tiempo real.
- Descarga la imagen generada como PNG.
- Copia la imagen al portapapeles.

## Cómo usar

1. Abre `index.html` en tu navegador.
2. Escribe el contenido del QR.
3. Ajusta tamaño y colores.
4. Haz clic en "Generar QR" y luego en "Descargar PNG".

## Archivos principales

- `index.html` — estructura de la aplicación.
- `styles.css` — estilos visuales modernos.
- `script.js` — lógica para generar y descargar QR.

## Tecnologías

- HTML5
- CSS3
- JavaScript
- QRCode.js
